Each project has one primary category for browsing. Some serve several purposes: Rook operates storage on Kubernetes, for example, so it appears with storage projects. Categories describe purpose, not importance, health, or a position in a universal software stack.

Dependency relationships are shown separately on individual project pages. Being in the same category does not imply that projects depend on one another.
