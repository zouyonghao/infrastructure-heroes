### Overview

Terraform is an open-source infrastructure as code software tool that enables users to define and provision data center infrastructure using a declarative configuration language.

### Importance

- Industry standard for infrastructure as code
- Supports all major cloud providers
- Foundation for reproducible infrastructure
- Essential for DevOps and platform teams

### Key Features

- Declarative configuration language (HCL)
- Provider ecosystem for any API
- State management and planning
- Module system for reusability
